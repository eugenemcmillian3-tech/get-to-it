# Deployment

GET TO IT deploys from the `main` branch of `eugenemcmillian3-tech/get-to-it` to the Vercel project `get-to-it`.

- Production URL: https://get-to-it-five.vercel.app
- Vercel production branch: `main`
- Supabase platform project: `get-to-it-phase1` (`yrnmqnubpuejwlkdhoub`)
- Vercel environment names: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_OAUTH_CLIENT_ID`, `SUPABASE_OAUTH_CLIENT_SECRET`, `SUPABASE_OAUTH_REDIRECT_URI`

Never put a Supabase service-role key in the browser or repository. Keep commits authored with the GitHub account's noreply address so Vercel's Git-author check accepts them.
